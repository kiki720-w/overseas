# Overseas 4.0.3 基础使用

1. 启动应用。新工作区为空，先在设置中填写工厂名称、产品和可核实能力。仓库中的模板和示例为虚构练习资料。
2. 导入客户前核对 CSV/XLSX 字段映射和预览，确认后再写入。保存重要资料前自行备份工作区。
3. 在模型连接和发现客户的搜索连接中配置自己的服务商、地址、模型和 Key。模型、搜索和在线 Fetch 需要网络与供应商权限，可能产生供应商费用。重启不自动恢复 Key；明确保存和恢复凭证是独立操作。
4. 搜索结果先作为来源页面审阅。目录、平台条目、搜索摘要与官网正文的证据强度不同；它们不能单独证明公司身份、采购需求或真实采购意图。检查来源、时间、引用和冲突，再决定是否添加客户。
5. 上传知识资料后检查解析结果、来源及选用范围。OCR/RAG 需要独立配置对应运行时及模型；源码仓库不自带这些大文件。增强检索默认关闭，缺少组件时查看界面状态，不把降级结果当作已完成模型推理。
6. 生成分析或回复前检查本次发送内容及授权。草稿需人工核对，应用不自动向客户发送邮件。工厂自述和历史证据不等于当前已独立验证的事实。
7. 备份与恢复需显式操作；升级、卸载或迁移前另外保管重要数据。源码开发使用独立工作区，避免同时打开同一个业务数据库。

安装版通常使用 %LOCALAPPDATA%/Programs/Overseas 保存程序，%LOCALAPPDATA%/Overseas/workspace 保存业务资料。源码启动以 launch.example.json 指定的独立目录为准。不要把工作区、日志或备份提交到 Git。

4.0.3 安装交付包含独立 OCR/RAG 组件；本仓库提供应用源码和打包入口，不包含安装包、模型、运行时。安装包的签名、干净 Windows 环境验证及第三方二进制再分发资格应单独核验。
